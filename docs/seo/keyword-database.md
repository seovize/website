## Methodology note / confidence caveat

- **GSC columns are real, live-pulled data** (Country: United States filter, 3-month window, pulled 2026-08-01). These are the only rows with actual impression/click/position numbers — everything else is `—` because Seovize has no recorded US impressions for that term.
- **SERP page type / local pack / dominant intent** come from WebSearch results, which return currently-ranking real pages but are **not geo-injected Google SERP scrapes** — no guaranteed top-10 order, no verified local-pack presence per query. Treat as directional, not GSC-grade. Confidence is marked accordingly per row.
- **Full US GSC query list (18 total, 3 months, 0 clicks on all of them):** `dallas seo services` (92 impr, pos ~78–92 range), `dallas seo company` (35), `dfw seo` (5), `site:seovize.com` (4), `dallas seo` (4), `website seo dallas` (4), `dallas seo team` (3), `reciprocal link seo` (2), `seo agency dallas` (2), `site:http://seovize.com` (1), `reciprocal links seo` (1), `seo services` (1), `dallas shopify seo` (1), `dallas seo experts` (1), `dallas seo agency` (1), `dallas seo consultants` (1), `energy seo dallas` (1), `seo dallas` (1). **193 total US impressions, 0 US clicks, avg. position 77.9.**
- **The single biggest fact in this database:** every US query with any recorded impressions is a variant of "Dallas SEO." Zero recorded US impressions for Austin, Houston, San Antonio, social media management, semantic SEO, technical SEO, local SEO, or Next.js SEO — despite dedicated pages existing for all of them. That is not evidence those terms have no demand; it's evidence Seovize currently has no measured visibility for them. Site-wide indexation is thin (8/48 known pages indexed per GSC Page Indexing report), which is the more likely explanation than lack of demand — see Phase 8.
- **Correction:** an earlier draft of this note called `reciprocal link(s) seo` impressions "noise." That was wrong — `next.config.ts` has a real 301 redirect from the old WordPress post `/what-are-reciprocal-links-in-seo-their-impact-on-rankings` to `/blog/reciprocal-links-seo`, a real existing blog post. These are legitimate residual impressions from that migrated post, not mis-classification. Left out of the commercial keyword clusters in Phase 2 because the intent is informational/blog, not a service page target — that part of the original note stands.
